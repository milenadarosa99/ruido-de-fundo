# ruido-de-fundo
O QUE É:
  Ruído de Fundo é uma plataforma fictícia para registro e compartilhamento de relatos sobre anomalias, lendas urbanas, fenômenos inexplicáveis e eventos estranhos.

TECNOLOGIAS:
  HTML5
  CSS3
  JavaScript
  PHP
  MySQL

FUNCIONALIDADES:
  Cadastro de usuários
  Login
  Feed de ocorrências
  Perfil do usuário
  Registro de relatos

OBJETIVO:
  Projeto acadêmico desenvolvido para praticar desenvolvimento web full stack.
